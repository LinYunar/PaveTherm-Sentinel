# 路表温度模型 — 参数选择与校准

## 公式(已实施,scripts/model.py)

```
T_pavement = T_air
           + α_rad × GTI                    # 太阳辐射升温
           + color_abs × (GTI / 800) × 2.5  # 颜色吸收率修正
           + age_correction(age_years)      # 老化年数补偿
           − 0.5 × wind_speed               # 风冷
```

## 各参数的物理意义与选择依据

### α_rad = 0.035 (°C per W/m²)

- **作用**: 每 W/m² 太阳辐射产生的路表升温
- **SHRP 文献范围**: 0.025 ~ 0.050 (差异巨大,取决于路面类型和风)
- **本 skill 取值**: 0.035,**偏上限**
- **理由**: 风险预警场景,**宁误报不漏报**。红警漏报代价 >> 黄警误报代价
- **校准路径**: 收集 ≥30 个实测样本(气温/GTI/实测路表),线性回归求解最优 α_rad

### color_abs (路面颜色吸收率)

| 颜色 | α | 实测对应 |
|---|---|---|
| black (新铺) | 0.92 | 表面沥青膜完好,接近黑体 |
| gray (中度老化) | 0.80 | 表面氧化,集料微露 |
| light_gray (严重老化) | 0.65 | 集料大量外露,泛白 |
| unknown (兜底) | 0.78 | 介于 gray 和 black 之间 |

- **数据来源**: 沥青混合料反射率文献(集料类型/级配差异 ±0.05)
- **物理**: 深色路面吸收更多短波辐射,转化为热;浅色路面反射多

### age_correction (老化年数补偿, °C)

```python
{0: 0.0, 5: 0.5, 10: 1.0, 15: 1.2, 20: 1.0}
```

- **逻辑**:
  - 0-10 年: 表面氧化,颜色变深,吸收率上升,升温 +0.5~1.0°C
  - 15 年峰值: +1.2°C
  - 20+ 年: 集料剥落,表面粗糙度增加,有效吸热面积下降,补偿回落
- **来源**: LTPP 长期性能观测的经验规律,**未实测校准**(🟡 ASSUMED)

### wind_correction = -0.5 °C per (m/s)

- **逻辑**: 风强制对流降温
- **依据**: 经典对流换热系数 h ≈ 5-15 W/(m²·K) 在 2-5 m/s 风速下
- **简化**: 线性化取 0.5, 风速 <1 m/s 时几乎不降温, 5 m/s 时 -2.5°C

## 已知偏差方向

**本模型系统性偏高 5-10°C, 在以下场景最明显**:

1. **晴天午后极热**(气温 ≥35°C + GTI ≥700)
2. **路面已严重老化(gray/light_gray)**(补偿系数不确定)
3. **未知颜色 + 未知年限**(双重 ASSUMED)

**系统性偏低 0-3°C, 在以下场景**:

1. **深夜无辐射时**(模型按 0 辐射处理,实际夜间路表 > 气温 + 滞后)
2. **风速 >5 m/s**(线性风冷系数低估对流强度)

## 校准路线图(用户实测数据进来后)

### Level 1 — 线性回归校准 α_rad

收集数据:
```csv
datetime,air_temp,gti,wind_speed,color,age_years,measured_pavement_temp
2026-07-15T14:00,33.2,720,1.5,black,5,62.5
```

回归:`T_pavement = β₀ + β₁·T_air + β₂·GTI + β₃·wind`,反推 α_rad ≈ β₂。

### Level 2 — 分颜色亚组

```python
# 按 pavement_color 分组建模, 每组单独校准
for color in ["black", "gray", "light_gray"]:
    subset = df[df.color == color]
    model.fit(subset)
```

### Level 3 — 机器学习替换

≥1000 样本后, XGBoost / LightGBM 通常能把 MAE 从 ±5°C 降到 ±2°C。特征:
- T_air, GTI, cloud_cover, wind_speed, humidity
- 颜色 one-hot, 年数 log
- 时刻(小时)周期性编码
- 历史 24h 滚动平均(路面热惯量)
